# PMSS 原始报价：同价多解、最优出力范围与真实中标联合验证（阶段七）

## 核心发现（仅历史样本）

在老师 PMSS 2025-09-01 的 39 节点、46 条线路、10 台机组、24 小时的真实脱敏历史案例中，以单个 DC-LP 解计算出的机组中标量 MAE 约 47.10233 MW。但单个求解器返回的最优解不一定是唯一的市场出力分配，因此不能直接断言成本最小化目标有误。

新增模块严格保留当天原始报价和网架，在相同最低报价成本 + 透明数值容差的可行集合内，**分别**优化各个机组出力下界与上界，再把 PMSS 真实整组发电量**同时固定**检查是否在同一个网络可行集合、是否仍达到最低报价成本。

| 指标 | 结果 |
|---|---:|
| 存在多组近似同成本最优出力的小时 | 22 / 24 |
| 单独机组历史中标处于本地最优区间的观测 | 240 / 240 |
| PMSS 历史整组中标在 DC 模型中联合可行的小时 | 24 / 24 |
| PMSS 历史整组中标在 DC 模型中达到最低申报报价成本的小时 | 24 / 24 |
| 整组中标申报成本差额最大值 | 小于 1e-8（浮点数值残差） |
| 每个机组小时最优范围宽度的简单均值 | 约 91.95 MW |

**解读：** 在该日期和该模型假设下，老师的整组历史中标量是一个可行、报价成本近似相同的解，单个 LP 解与 PMSS 的机组出力误差很可能很大程度涉及**多个并列最优解的选择机制**。

**严格限制：** 单独机组上下界不能任意拼成同一个可行解，因此额外做了“整组真实机组 MW 同时固定”的 LP 联合验证。这也**不能证明**两套市场规则、启停约束、节点电价或补偿结算机制一致；原历史日期的本地 DC 节点价格 MAE 仍约 397.37（价格原始单位需核对）。当前只有一天真实历史样本，不能说明未来市场也有类似特征。

## 历史零出力敏感性实验

在 10 机组×24小时共240个历史单元时段中，有22个零出力记录。对这些机组小时增加明确的零容量限制，结果为：

- 原本本地基准 DC 模型对这些历史零出力机组已全部分配0MW；
- 即使约束不改变它们的出力，求解器仍在16个小时重排其他机组的出力，市场最低报价成本变化处于约 1e-9 数值量级；
- 单个最优解的机组中标量 MAE 从 47.10MW 变为 13.02MW，但节点电价 MAE 仍没有改善。

因此这不是“证实了实际机组停机约束”。**零出力并不必然表示停机**，尤其历史机组最小技术出力字段都为0。事后零出力限制完全不能当作新报价的预测信息。该实验更直接支持**退化优化模型的不同最优基可能显著改变出力分配**这一研究假设。

## 实现的代码

- src/powerbid/network_dispatch.py：新增可选 forced_off_units 参数；默认行为保持不变，只用于明确的离线诊断。
- src/powerbid/expost_commitment_diagnostics.py：同一天原始报价的历史零出力敏感性试验、可比小时及缺失数据处理。
- src/powerbid/optimal_dispatch_ranges.py：在最低报价成本面内分别求各机组输出最小/最大范围；再对整组历史发电量增加等式约束，检查其联合可行性及与最低成本的差额。
- src/powerbid/historical_ambiguity.py：24小时原始报价最优区间、联合可行性和真实观测完整性汇总。
- app/pages/6_模型可靠性回测.py：研究页面新增多解/联合最优成本与零出力敏感性诊断；报告仅输出指标。
- tests/test_optimal_dispatch_ranges.py、tests/test_historical_ambiguity.py、tests/test_expost_commitment_diagnostics.py：等价成本多解、唯一解、网络阻塞、缺失、不可行、市场身份限制和历史联合验证的合成测试。

运行：安装 pip install -e '.[ui,strategy]'；执行 streamlit run app/streamlit_app.py，进入“模型可靠性回测”并导入已授权脱敏历史快照。不要将真实私有源文件放入 GitHub。新模块不会登录 PMSS、提交报价或执行出清。

## 后续优先级

1. 查证老师 PMSS 的并列最优选择方式与成本报价梯度、历史保存的超当前上限报价是否有相同运行口径。
2. 查证 SCUC/SCED 机组连续运行、爬坡、备用、辅助服务、总费用补偿与节点价格形成规则。不要把无法识别的规则硬编码为确定事实。
3. 针对同价报价添加**自主可解释的确定性次级选择规则**并测试稳定性，但不得冒称它就是老师平台的真实规则。
4. 增加独立日期、独立工况的只读历史案例与留出检验，并且仅在获得明确授权的教学测试环境中有限次实际重出清，才能评价新报价的真实 PMSS 成绩。

所有本次统计**仅对应 2025-09-01 一天，且是原历史出清结果**；不代表任何新报价方案的真实 PMSS 中标、结算收入或未来利润。
