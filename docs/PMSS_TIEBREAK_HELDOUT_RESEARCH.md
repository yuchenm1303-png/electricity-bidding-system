# 第十八阶段：三天历史的“提前锁定规则—第三天检验”实验

## 核心问题

早前仅在2025-09-01单日真实PMSS案例上测试不同同成本分配，发现“机组ID正序优先”得到约19.44MW机组中标MAE、原始输入顺序LP约47.10MW，但**不能仅凭当日最优表现宣称老师平台真实使用正序规则**。

现在另一个开发分支已取得2025-09-01/02/03三天真实、具有对应24小时原始报价、39节点/46线路和10机组历史出清的只读案例，并已合并`docs/PMSS_THREE_DAY_RESEARCH_2025-09.md`。9月2日/3日原始报价相同，日期独立**不等于报价曲线多样性独立**。

本阶段新增严格按日期先后分割的**原报价DC调度重放**规则实验。它检查先前发现的机组分配误差是不是仅仅当天的偶然拟合，而非追加新报价预测器。

## 方法

`src/powerbid/pmss_tiebreak_holdout.py`：
1. 接收3～12份完全独立日期、同一DC网络/机组/线路身份的历史快照，仅使用当日原始报价、当日逐节点负荷和记录的实际中标结果；禁止重复日期、错误网架、缺少整天出力观测。
2. 排除“原始文件段顺序LP”作为可选择规则，避免JSON排列改变其结果；将其只保留为参考。事先声明三个候选：规范化报价段顺序普通LP、机组ID正序、机组ID倒序。它们只改变**同一最低报价成本下的次级分配**，不改变主报价成本目标。
3. 按时间升序，以最早至少两天的**原始报价中标量MAE**选择规则，明确按固定顺序处理并列误差，**先确定并锁定规则**。
4. 此后才读取最后至少一天的PMSS真实中标结果，独立计算锁定规则和所有预先声明规则的测试误差；绝不使用最后一天的MAE反过来重新选择训练赢家。
5. 计算不同日期之间“原始报价曲线完全相同”的日期对数，提醒部分日期的报价不具有独立多样性。报告只返回日期、聚合MAE、锁定规则、训练和留出差值、警告与`validatedNewBids=false`；**不输出机组ID、真实报价、项目ID、真实出力或敏感原始行**。

`scripts/report_pmss_tiebreak_holdout.py`：离线读取3～12份授权可访问的私有原始历史快照，只生成一个新的0600匿名研究报告文件，使用独占创建拒绝覆盖已有文件。无任何老师平台登录、报价提交或重新出清。

## 示例运行

仅在有权读取三份真实私有历史案例的可信主机上：

```bash
python scripts/report_pmss_tiebreak_holdout.py \
  --holdout-dates 1 \
  --output /private/pmss-tiebreak-holdout-audit.json \
  /private/2025-09-01.json \
  /private/2025-09-02.json \
  /private/2025-09-03.json
```

输出中的 `policyLockedUsingTrainingOnly` 只表示在9月1日+2日上误差最低的**本地DC模型同成本分配约定**。`holdoutMaeMwByPolicy` 是9月3日原报价重放下的历史中标量误差。不含老师真实同价排序依据、新报价反事实出清、中标利润、未来收益或清算结果。

## 限制与数据安全

- 三天历史数据原始内容仍仅存于私有服务器。若服务器的历史输入由root:root 0600保护，**开发账号不绕过该权限读取**；应由授权管理员在已有权限下运行工具。
- 三天历史结果对全部机组覆盖，并不证明 PMSS 真实物理约束、启停成本、AC潮流、电价截断方式已经被本地模型准确模拟。
- 机组ID正序/倒序纯属预设的数学分配约定；哪套规则在日期留出评估更好，仍可能只反映日负荷和线性规划求解器的退化结构。
- 不能将`holdoutBestPolicyExPostDiagnosticOnly`冒称外推前确定的规则，不能用第三天数据进行调参后仍将其称为未见测试集。
- 当前只有一个3日连续窗口，样本偏小；9月2日/3日还存在报价重复，因此这只是**初步时间留出检查**，绝不构成新报价收益预测验证。

## 测试

使用合成同成本网络验证：训练两天与第三天出现相反的中标选择，锁定规则不得随未来观测变化；JSON输入顺序随机变化也不能改变日期分割；缺数据、重复日期、不同线路/机组映射拒绝；CLI新私有文件0600且不得覆盖；敏感原始字段、项目及机组标识不写入匿名报告。

建议结合`docs/PMSS_THREE_DAY_RESEARCH_2025-09.md`已有三天原始报价DC回放/节点价格/固定实际出力潮流报告综合分析。在老师课程规则和真实新报价反事实数据得到额外验证前，正式报价和利润引擎**保持现状**。
