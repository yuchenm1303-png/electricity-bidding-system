# PowerBid 策略研究室（V2，离线代理市场模型）

## 本次实现

新增模块 src/powerbid/strategy_lab.py 和独立 Streamlit 页面 app/pages/2_策略研究室.py。

基于可脱敏的 PMSS 快照和显式的 24h 负荷输入，在本地生成与比较：

1. **固定成本加价**：各段采用运行成本参数 + 加价。
2. **逐段阶梯加价**：在固定加价上，对高电量段按序增价。
3. **负荷自适应**：根据预测负荷 / 系统申报容量增加紧张时段溢价，并保留阶梯价格。
4. **历史已报曲线基准**：作为本地反事实比较基线，不声称这是实际 PMSS 的利润。

默认扫描多个加价档位，每档位生成三种策略。当前尚非神经网络、强化学习，也未实现全局最优搜索。

## 时间规则严格遵守 PMSS

- useSameBiddingCurve=1：所有策略对 24h 只生成一条曲线。负荷自适应策略使用预测日内的最紧张小时来定价。
- useSameBiddingCurve=0：每个小时可以生成独立曲线，最紧张时段溢价可以不同。
- 按已解析的 unitPowerDeclareSegmentConstraint 控制最多 5 段。
- 每段包含累计 MW 起止界与报价价格；默认将机组最小技术出力标记为第一段上界。但这**不是**强制最小出力约束；无机组启停、爬坡模拟。
- 历史已保存的报价可能越过市场规则接口的名义价格上限，当前不自动修正。报价提交前仍需独立校验。

## 评价过程

输入：运行成本参数、原始机组报价、显式负荷预测、目标机组、策略列表、风险参数。

对每一个策略，构造相同的 synthetic 压力情景（负荷低/中/高 × 竞争对手报价格低/中/高）；逐小时用内置单区域统一价引擎出清，然后计算：

    模拟小时利润 = (模拟出清价 - runningCost) × 本机组模拟中标MW × 1小时
    模拟24小时利润 = sum(模拟小时利润)
    期望利润 = sum(情景概率 × 模拟24小时利润)
    下行利润 = 最差 tail_fraction 概率质量中的加权平均利润
    策略评分 = (1 - 风险厌恶) × 期望利润 + 风险厌恶 × 下行利润

只有在所有 synthetic 情景的模拟市场都能供足负荷时才可推荐。本机制不会将历史结果作为未来真实价格预测，也不会把利润变化冒充 PMSS 正式增益。

## 已知边界

**与真实 PMSS 相比，本版本仍缺：**

- 节点 LMP、线路潮流和阻塞约束
- 机组最小技术出力的实际出清约束、启停成本、最短开停机时间、爬坡
- 日前与实时耦合，以及平台实际结算规则
- 实际预测数据与概率校准、竞争者行为学习
- PMSS 候选报价试验与多轮真实出清反馈

特别地，runningCost 被当作常数边际成本（单位须核实）。无法证明本地推荐报价在老师平台可行或最优。

## 使用

安装 UI：pip install -e '.[ui]'；运行 streamlit run app/streamlit_app.py。

通过左侧 Streamlit 页面导航打开“策略研究室”，上传**已经脱敏**的 PMSS 只读快照（格式与现有五段报价页一致）。选择机组、加价范围、风险偏好和负荷/竞争报价偏差，运行“比较所有报价策略”。

页面仅生成用户审阅 JSON（不含认证、scopeId 或项目 ID），**不会通过网络请求写入或触发 PMSS 出清**。新页面与另一窗口负责的 PMSS adapter 分离，可并行维护。

自动化验证：python -m pytest tests/test_strategy_lab.py -q；python -m ruff check src/powerbid/strategy_lab.py tests/test_strategy_lab.py app/pages/2_策略研究室.py。
