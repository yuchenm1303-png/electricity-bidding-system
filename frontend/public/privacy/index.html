隐私政策

生效日期：2026 年 10 月 13 日

PowerBid Studio（以下简称“本平台”）是面向电力市场教学、研究和报价策略分析的网页应用。本政策说明我们在提供账号登录、模型分析和教学实验功能时涉及的信息与处理方式。

一、我们处理的信息

  • 账号信息：您注册时提供的用户名、邮箱，以及经加密哈希处理的密码；同时记录账号状态、角色和创建时间。
  • 第三方登录信息：如您选择 Google 或 GitHub 登录，我们从相应身份提供方获取用于识别账号的唯一标识及经过验证的邮箱。第三方授权过程中可能涉及临时授权令牌。
  • 使用和安全信息：登录会话、必要的认证状态、防滥用尝试和服务器访问记录等。
  • 教学与分析内容：您主动输入、上传或在工作台中处理的电网、机组、报价与仿真相关数据。具体处理和保存方式取决于使用的功能及其提示。

二、使用目的

我们处理上述信息是为了提供账号注册与登录、保持登录状态、管理访问权限、执行您请求的报价与仿真分析、维护平台安全，以及排查故障和改善服务。不会将第三方登录信息用于未经您同意的其他账号操作。

三、第三方服务与数据传输

您主动选择 Google 或 GitHub 快捷登录时，会跳转至对应服务的授权页面，身份验证由其完成；相关提供方可能依据其自身隐私政策处理登录信息。平台的 PMSS 教学系统连接属于独立功能；只有在用户明确使用相关功能时，才会按界面说明与对应教学环境交互。我们不会因为您通过 Google 或 GitHub 登录，就自动向 PMSS 提交报价。

四、Cookie 与保存期限

平台使用必要的登录会话 Cookie 维持身份验证，通常最长有效期为 7 天；服务器可提前使会话失效。账号资料在账号存在期间保存，必要的安全和访问记录依据运行及安全需要管理。您可以通过下方联系方式咨询信息查阅、更正及删除事宜。

五、信息安全

平台通过 HTTPS 传输网页数据，使用密码哈希、受保护的会话 Cookie 和账号权限控制等措施降低风险。任何网络服务都无法保证绝对安全；请不要在教学数据、报价备注或支持请求中填写不必要的个人敏感信息。

六、您的选择和权利

您可选择使用密码登录或在启用后使用 Google、GitHub 登录。若要咨询访问、更正或删除与您有关的账号信息，或反馈隐私问题，请发送邮件至 yuchenm1303@gmail.com。为防止他人未经授权修改账号，处理请求前可能需要确认账号所有权。

七、政策变更

如功能或数据处理方式发生变化，我们将相应更新本政策，并在本页面标明最新日期。
